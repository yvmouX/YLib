# YLib 多语言系统（MessageService）

YLib 提供了一套轻量的多语言消息服务：自动管理语言文件（jar 内默认 + 用户文件双向同步）、
数字占位符、颜色码转义、前缀拼接，并可选按玩家客户端语言显示消息。

## 快速开始

### 1. 准备语言文件

在插件 jar 内放置默认语言文件。服务会优先按语言目录查找 jar 默认文件，未命中再回退到资源根目录
（兼容旧版打包），建议按目录组织（默认语言目录 `lang`）：

```
src/main/resources/
└── lang/                      # jar 内默认语言文件（也可直接放资源根目录）
    ├── lang_en.yml
    └── lang_zh_CN.yml
```

```yaml
# lang_zh_CN.yml
prefix: "&8[&b&lMyPlugin&8]&r "

greeting: "&a你好，{0}！"
welcome: "&e欢迎来到服务器，今天是第 {0} 天。"
```

### 2. 创建并使用消息服务

```java
public class MyPlugin extends JavaPlugin {

    private MessageService messages;

    @Override
    public void onEnable() {
        YLib ylib = YLib.getYLib();

        messages = ylib.createMessageService(MessageSettings.builder()
                .defaultLanguage("en")                    // 缺失键的回退语言
                .availableLanguages("en", "zh_CN")        // 可用语言
                .filePattern("lang_%s.yml")               // 语言文件名模式（仅文件名）
                .languageFolder("lang")                   // 语言文件目录，默认 lang（可自定义）
                .prefixKey("prefix")                      // send() 自动拼接的前缀键
                .useClientLocale(false)                   // 是否按玩家客户端语言
                .build());

        // 发送带前缀的消息
        messages.send(sender, "greeting", player.getName());

        // 获取消息文本（不带前缀）
        String text = messages.raw("welcome", day);

        // 切换全局语言
        messages.setLanguage("zh_CN");

        // 重载语言文件
        messages.reload();
    }
}
```

### 3. 语言文件管理

*   **首次启动**：`plugins/<插件名>/lang/` 下不存在对应文件时，自动从 jar 内默认生成；
*   **升级补键**：jar 默认文件中新增的键会自动补进用户文件（保留用户已有改动与注释）；
*   **查找链**：当前语言用户文件 → 当前语言 jar 默认 → 默认语言 → 告警并返回 `Missing message: <key>`。

## 自定义语言文件位置

语言文件默认生成在插件数据文件夹的 `lang/` 子目录，通过
`MessageSettings.Builder#languageFolder(...)` 可在创建消息服务时自定义：

```java
// 1. 其他相对目录（相对插件数据文件夹）
.languageFolder("messages")

// 2. 放回插件数据文件夹根目录（旧版行为）
.languageFolder("")

// 3. 绝对路径（如跨插件共享语言目录）
.languageFolder(new File(serverDir, "plugins/Shared/lang").getPath())
```

> 注意：使用相对目录时，jar 内默认文件也会优先按 `<目录>/<文件名>` 镜像查找，
> 未命中再回退到资源根目录；使用绝对路径时 jar 默认文件只在资源根目录查找。

## 占位符与颜色

消息占位符为数字风格 `{0}、{1}…`，按 `raw/send` 的可变参数顺序替换：

```yaml
item-given: "&a已给予 {0} {1} 个物品"
```

```java
messages.send(sender, "item-given", target.getName(), amount); // {0}=玩家名 {1}=数量
```

*   未提供的占位符会被**静默移除**（避免 `{2}` 泄漏到聊天栏）；
*   `&` 颜色码统一转义为 `§`，已转义文本不受影响。

## 按玩家客户端语言

```java
MessageSettings.builder()
        .useClientLocale(true)
        ...
```

开启后，`send(sender, ...)` 与 `raw(sender, ...)` 会按玩家客户端设置解析语言：

1.  精确匹配可用语言（`zh_cn` ↔ `zh_CN`，忽略大小写）；
2.  语言段匹配（`en_us` → `en`）；
3.  均未命中 → 回退全局语言。

控制台与非玩家发送者始终使用全局语言（`getLanguage()`）。

## 与 Minecraft 客户端语言代码互转

插件若需要按语言加载 Minecraft 原版翻译（如物品名本地化），可用内置映射：

```java
messages.getMinecraftLanguageCode("en");    // → "en_gb"
messages.getMinecraftLanguageCode("zh_CN"); // → "zh_cn"
```

默认映射：`en → en_gb`、`zh_CN → zh_cn`；可通过 `addMinecraftLanguageCode(...)` 追加。

## API 参考

| 方法 | 说明 |
|------|------|
| `getLanguage()` | 当前全局语言代码 |
| `setLanguage(code)` | 切换全局语言（须在可用语言内） |
| `getAvailableLanguages()` | 可用语言列表 |
| `has(key)` | 键是否存在 |
| `raw(key, args…)` | 消息文本（不带前缀） |
| `raw(sender, key, args…)` | 同上，useClientLocale 开启时按玩家解析 |
| `send(sender, key, args…)` | 发送 前缀 + 消息 |
| `sendRaw(sender, message)` | 发送 前缀 + 自定义文本 |
| `prefix()` | 配置的前缀（未配置返回空串） |
| `getMinecraftLanguageCode(code)` | 插件语言 → MC 客户端语言 |
| `reload()` | 重载所有语言文件 |
