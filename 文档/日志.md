# YLib Logger System

YLib 提供了一个简洁且功能丰富的日志接口，支持颜色代码、调试模式过滤以及多目标输出。

## 核心接口：Logger

`Logger` 接口统一了日志操作，底层自动适配控制台输出格式。

### 获取实例

通常通过 YLib 实例创建，可以指定前缀。

```java
// 创建一个带前缀的 Logger: [MyPlugin]
Logger logger = YLib.getInstance().createLogger("MyPlugin");
```

---

## 基本用法

### 日志级别

```java
// 普通信息
logger.info("插件启动成功！");

// 警告信息
logger.warn("检测到配置文件版本过旧");

// 错误信息
logger.error("连接数据库失败: %s", "Connection timed out");

// 调试信息（仅在开启调试模式时显示）
logger.debug("处理玩家 %s 的数据...", player.getName());
```

### 支持格式化

所有方法都支持 Java `String.format` 风格的参数替换：

```java
logger.info("加载了 %d 个任务，耗时 %.2f ms", taskCount, timeMs);
```

### 支持颜色

可以直接传入 `ChatColor` 来设置消息颜色（会自动重置）：

```java
import org.bukkit.ChatColor;

logger.info(ChatColor.GREEN, "操作成功完成！");
logger.error(ChatColor.RED, "发生严重错误！");
```

---

## 高级功能

### 定向输出 (To Player)

可以将日志重定向发送给特定玩家或 `CommandSender`，这在调试命令或给管理员发送通知时非常有用。

```java
// 这条日志不会发给控制台，而是直接发给玩家
logger.toPlayer(player).info("你的数据已保存。");

// 发送警告给玩家（通常显示为黄色或红色）
logger.toPlayer(sender).warn("你没有权限执行此操作。");
```

### 配置选项 (LoggerOption)

在创建 Logger 时可以指定选项：

```java
// 创建一个开启 DEBUG 模式并支持 ANSI 颜色的 Logger
Logger customLogger = YLib.getInstance().createLogger("DebugLogger", LoggerOption.DEBUG);
```

*   `LoggerOption.DEBUG`: 允许输出 `debug()` 级别的日志。如果不开启，调用 `debug()` 不会有任何反应。
*   `LoggerOption.ANSI`: 允许在控制台输出 ANSI 颜色代码（视服务端支持情况而定）。
