# YLib Configuration System

YLib 提供了一个强大且现代化的配置管理系统，基于 **注解驱动 (Annotation-Driven)** 和 **POJO 映射 (Object Mapping)** 设计。

## 为什么选择 YLib 配置系统？

*   **类型安全**：直接操作 Java 对象字段，而非弱类型的 `config.get("path")`。
*   **零样板代码**：不需要手动编写 `load()`, `save()`, `reload()` 逻辑。
*   **自动验证**：支持声明式验证规则（如 `min:1`, `range:1-100`），在加载时自动检查数据合法性。
*   **版本迁移**：内置自动备份与迁移功能，轻松应对插件版本更新后的配置结构变更。
*   **热重载**：支持运行时重载并触发变更事件。

## 快速开始

### 1. 定义配置类

创建一个普通的 Java 类，并添加注解。这个类就是你的配置文件模型。

```java
import cn.yvmou.ylib.api.config.AutoConfiguration;
import cn.yvmou.ylib.api.config.ConfigValue;

// 定义配置文件名称、版本号和基本信息
// configFile: 相对于插件数据文件夹的路径
// version: 配置版本号，用于自动迁移
@AutoConfiguration(configFile = "settings.yml", version = "1.0.0")
public class SettingsConfig {

    @ConfigValue(value = "server.host", description = "数据库主机地址")
    private String host = "localhost";

    @ConfigValue(value = "server.port", validation = "range:1-65535")
    private int port = 3306;

    @ConfigValue(value = "features.enabled")
    private boolean featuresEnabled = true;

    // 支持枚举自动转换
    @ConfigValue(value = "log-level")
    private LogLevel logLevel = LogLevel.INFO;

    public enum LogLevel { INFO, DEBUG, WARN }

    // Getters...
    public String getHost() { return host; }
    public int getPort() { return port; }
}
```

### 2. 注册配置

在你的插件启动逻辑（`onEnable`）中注册该配置类。

```java
public class MyPlugin extends JavaPlugin {
    
    @Override
    public void onEnable() {
        // 获取配置管理器
        ConfigurationManager configManager = YLib.getInstance().getConfigurationManager(); 
        
        // 注册配置
        // 这一步会自动加载文件、验证数据、处理迁移
        SettingsConfig settings = configManager.registerConfiguration(SettingsConfig.class);
        
        // 使用配置
        getLogger().info("Server Host: " + settings.getHost());
    }
}
```

## 核心注解详解

### @AutoConfiguration

标记在类上，定义配置文件的元数据。

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `value` | 配置组名称（内部标识用） | 类名去后缀 |
| `configFile` | **(必需)** 配置文件路径 | - |
| `autoCreate` | 文件不存在时是否自动生成 | `true` |
| `version` | 配置版本号，用于触发迁移 | `"1.0.0"` |

### @ConfigValue

标记在字段上，映射 YAML 中的键值。

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `value` | **(必需)** YAML 路径 (如 `database.host`) | - |
| `description` | 字段注释，生成文件时会写入 | `""` |
| `required` | 是否为必需字段，缺失会报错 | `false` |
| `validation` | 验证规则表达式 | `""` |
| `sensitive` | 是否敏感信息（日志脱敏） | `false` |

## 支持的数据类型

YLib 支持自动将 YAML 值转换为以下 Java 类型：

*   **基本类型**: `int`, `long`, `double`, `float`, `boolean`
*   **字符串**: `String`
*   **枚举**: `Enum` (不区分大小写)
*   **集合**: `List<?>` (直接映射 Bukkit 的 List)

---

## 验证规则 (Validation)

通过 `validation` 属性定义规则，多个规则用逗号 `,` 分隔。

| 规则 | 格式 | 示例 | 说明 |
|------|------|------|------|
| **最小值** | `min:N` | `min:10` | 数值 >= N |
| **最大值** | `max:N` | `max:100` | 数值 <= N |
| **范围** | `range:N-M` | `range:0-100` | N <= 数值 <= M |
| **长度** | `length:N` | `length:32` | 字符串长度 = N |
| **正则** | `regex:P` | `regex:^\w+$` | 匹配正则表达式 |
| **枚举** | `enum:A\|B` | `enum:TCP\|UDP` | 值必须在列表中 |

**示例**:
```java
@ConfigValue(value = "nickname", validation = "length:3-16,regex:^[a-zA-Z0-9]+$")
private String nickname;
```

## 自动备份与迁移

当你更新插件并需要修改配置文件结构时，只需更新 `@AutoConfiguration` 中的 `version`。

**流程**:
1.  开发者修改代码：增加字段，将版本从 `"1.0.0"` 改为 `"1.1.0"`。
2.  用户安装新版插件并启动。
3.  YLib 检测到版本不匹配。
4.  **备份**：旧文件重命名为 `settings_backup_v1.0.0.yml`。
5.  **生成**：生成包含新字段和新注释的 `settings.yml`。
6.  **迁移**：将旧文件中的有效值自动填入新文件。

## API 参考

### 获取配置实例
```java
// 获取已注册的实例
SettingsConfig config = configManager.getConfiguration(SettingsConfig.class);

// 获取必需的实例（未注册抛异常）
SettingsConfig config = configManager.getRequiredConfiguration(SettingsConfig.class);
```

### 重载配置
```java
// 重载单个配置
configManager.reloadConfiguration(SettingsConfig.class);

// 重载所有配置
configManager.reloadAllConfigurations();
```

### 监听变更
```java
configManager.addConfigurationListener(SettingsConfig.class, (oldConfig, newConfig) -> {
    if (oldConfig.getPort() != newConfig.getPort()) {
        getLogger().info("端口已变更，正在重启服务...");
    }
});
```

### 保存配置
```java
// 将内存对象的当前状态保存回文件
configManager.saveConfiguration(SettingsConfig.class);
```
